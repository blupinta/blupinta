# Contributing

Each library has its own repository ([blupinta-js](https://github.com/blupinta/blupinta-js),
[blupinta-python](https://github.com/blupinta/blupinta-python)): issues and pull requests go there. Those repositories
are published copies: the libraries are developed next to Blupinta's API, so that every change to the API and to its
clients is tested together before release. An accepted pull request is applied there and comes back with the next
release, crediting its author.

Security problems: see [SECURITY.md](SECURITY.md), never a public issue.
